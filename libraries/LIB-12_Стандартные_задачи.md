# LIB-12. Стандартные задачи для входного теста и контрольных точек

**Версия:** 1.0 · 2026-10-11 · **Объём:** 50 задач (S01–S50) + действующая задача входного теста S00 «кофейня».
**Где используется:** входной тест (B1, §3) и индекс первой мысли (B5, §3).

## Как обеспечена сопоставимость
Все задачи — **параллельные формы одного типа**: «привлечь новых клиентов или пользователей за месяц без рекламного бюджета». Отличается только контекст (вид дела). Поэтому:
1. все задачи оцениваются **одной** таксономией LIB-01 и одним словарём LIB-02. Отдельная таксономия на каждую задачу не нужна;
2. формулировка построена по единому шаблону: кто + что + сколько времени работает + «денег на рекламу нет» + «как за ближайший месяц привлечь …»;
3. виды дела выбраны знакомые большинству людей, без медицинских и юридически чувствительных тем и без сильной сезонности.

Инструкция одинакова для всех задач (как у S00): *«Напишите как можно больше идей — по одной на строку. Старайтесь придумывать необычные идеи, которые не пришли бы в голову большинству людей. Не останавливайтесь на первой удачной мысли: у вас 3 минуты»*.

**Остаточная разница в сложности** неизбежна. Она выравнивается по данным (A4, §2.8): ИПМ_норм = ИПМ − средний ИПМ всех участников на этой задаче. Пока у задачи меньше 30 ответов, сравнение помечается как предварительное.

**Порядок выдачи на контрольных точках:** по возрастанию номера, без повторов для пользователя. Группы чередуются (Л → Ф → П → Л …), чтобы человек не привыкал к одному контексту.

**Группы:**
- **Л** — локальный бизнес (25);
- **Ф** — услуги фрилансера (15);
- **П** — пет-проект (10).

## Замечания по сопоставимости
- **S45 и S50** имеют двойную цель (две стороны рынка или пользователи плюс помощники) и могут оказаться сложнее. Если данные это подтвердят, их стоит исключить из контрольных точек и оставить для тренировок.
- **S46 (гид)** зависит от туристического сезона. При контрольной точке зимой результат помечается.
- Задачи группы **П** могут быть труднее для людей без опыта в продуктах. Это проверяется средним ИПМ по группам. Если разница большая, контрольные точки выдаются только из одной группы на пользователя: той, что ближе к его роли из входного теста.
