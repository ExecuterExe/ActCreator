# LIB-06. Каталог операторов преобразования

**Версия:** 1.0 · 2026-10-11 · **Объём:** 80 операторов в 8 группах + 10 шаблонов скрещивания.
**Универсальны:** подходят для любой сферы. Связь с семействами дана для текущей сферы (LIB-01).

**Почему 80, а не 500.** Оператор — это **операция над конструкцией решения**: кто, когда, как устроено, сколько, что видно, что на что обменивается, где, зачем. Различных таких операций немного: в ТРИЗ, например, 40 изобретательских принципов. При 500 элементах сотни из них неизбежно оказались бы переформулировками одних и тех же операций — это брак по нашему критерию. Разнообразие формулировок достигается иначе: адаптацией оператора к задаче (Р5) и силой (ниже).

**Как читать строку:**
- **Шаблон** — задание пользователю. `[слоты]` заполняются из задачи.
- **Меняет** — какую часть конструкции решения.
- **Чаще ведёт в** — семейства LIB-01, куда оператор обычно выводит. Используется для выбора оператора под незанятое семейство (Д1). Связь экспертная, уточняется по данным пилота.
- **Пример** — нейтральная задача «привлечь новых читателей в районную библиотеку». Только для разметчиков, пользователю не показывается.

**Сила:**
- **1** — применить оператор к одной части решения;
- **2** — ко всему решению;
- **3** — ко всему решению **и** без привычного семейства пользователя.

Базовая сила оператора — насколько он радикален сам по себе. Итоговая сила = базовая ± решение дозировщика, в пределах 1–3.
