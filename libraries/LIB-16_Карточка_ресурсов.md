# LIB-16. Карточка ресурсов: поля, варианты, правила сопоставления

**Версия:** 1.0 · 2026-10-11 · **Объём:** 16 полей и 9 правил сопоставления.
**Где используется:** онбординг (B1, §4), диагноз Д4 (B2, §4), подбор незанятых семейств (A2, §2.4), критик пре-мортема (B4, §3), проверка за 48 часов (B4, §5).

**Принцип:** каждое поле должно влиять хотя бы на одно решение системы. Поле, которое ни на что не влияет, — брак: оно лишь удлиняет анкету.

**Полная версия:** все поля, около 5 минут.

## 2. Правила сопоставления с ресурсоёмкостью семейств (LIB-01)

Ресурсоёмкость семейства: Д, В, К, Н ∈ {Н, С, В}. Конфликт для правила Д4 и для фильтра навигатора:

| № | Правило | Условие конфликта |
|---|---|---|
| П1 | Деньги | R01 = 0 ₽ или «до 5 тыс.», а Д семейства = С или В |
| П2 | Время | R02 = «меньше 2 ч», а В семейства = В; или R02 = «2–5 ч», а В семейства = В и R03 = «за неделю» |
| П3 | Команда | R04 = «только я», а К семейства = С или В |
| П4 | Навыки | Семейству нужен навык (таблица ниже), которого нет в R05 |
| П5 | Нежелание | Семейство связано с пунктом R06 («писать незнакомым» → F05; «появляться на публике» → F01.3, F02.3, F12.1, F12.3; «вести соцсети регулярно» → F01; «скидки» → F07; «работать бесплатно» → F06) |
| П6 | Запрет задачи | R12: «без скидок» → F07; «без платной рекламы» → платная часть F02.1; «без холодных контактов» → F05.1; «без публичности» → F01, F02.3, F12 |
| П7 | Место | R15 = «только онлайн» → F11, F13.4, F14.1 (выезд) несовместимы |
| П8 | Экономика | R14 = «до 1 тыс. ₽» и семейство F06.1 или F06.4 (дорогая бесплатная работа) → предупреждение, а не запрет |
| П9 | Неизвестно | R01 = «не знаю» или поле пусто → правило не применяется; критик задаёт вопрос вместо возражения |

**Как используются конфликты:**
- **Навигатор** не предлагает семейства с конфликтами П5–П7: это прямые запреты пользователя.
- **Конфликты П1–П4** — материал для противоречия (Д4), а не повод скрыть семейство.

### Навыки, которые нужны семействам (для П4)
| Семейство / подсемейство | Нужный навык из R05 |
|---|---|
| F01.1, F01.2, F01.5 | писать тексты (или видео) |
| F01.3 | снимать и монтировать видео |
| F02.3, F12.1, F12.3 | выступать публично |
| F05.1–F05.3 | продавать и вести переговоры |
| F06.3, F09.5 | программировать (или конструкторы без кода) |
| F12.1–F12.5 | организовывать события |
| F11.4, F13.3 | дизайн и визуал |
