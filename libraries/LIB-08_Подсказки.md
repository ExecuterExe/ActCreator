# LIB-08. Банк шаблонов подсказок

**Версия:** 1.0 · 2026-10-11 · **Объём:** 300 шаблонов (коды: Q — вопросы, TR — переносы, FR — фрагменты; не путать с T-кодами LIB-10 и F-кодами семейств LIB-01):
- 120 вопросов (H-Q);
- 80 переносов (H-T);
- 100 фрагментов (H-F).

**Где используется:** этап «Своя идея» (B4, §1), бюджет до 3 подсказок за сессию. Коуч Р6 выбирает шаблон и подставляет слоты; без ИИ шаблон выбирает ведущий.

**Слоты:**
- `[клиент]` — кто клиент;
- `[цель]` — цель задачи;
- `[запрет]` — запрещённое ограничением;
- `[семейство]` — привычное семейство пользователя;
- `[целевое]` — незанятое семейство из навигатора;
- `[допущение]` — выбранное допущение;
- `[ресурс]` — из карточки.

**Обязательные правила для каждой подсказки:**
1. Не длиннее 2 предложений.
2. Не содержит готовой идеи: действия + канала + механизма вместе.
3. Не оценивает черновик.
4. Направляет внимание на механизм, людей, момент или ресурс, но решение оставляет пользователю.

**Запрещённые формы (брак):**
- «Например, можно…»;
- «Попробуйте сделать [конкретное действие]»;
- «Многие делают…»;
- «Хорошая идея, но…»;
- перечисление вариантов;
- описание чужого готового решения.

**Пример брака и исправления:**
- ❌ «Например, договоритесь с фитнес-клубом о взаимных рекомендациях» — это готовая идея.
- ✅ «Подумайте о тех, у кого ваши будущие клиенты уже бывают каждую неделю» — это фрагмент.
